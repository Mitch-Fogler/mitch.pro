========================================
            PORTAL CTF HINTS
========================================
1. Cipher Breach:
   - Plaintext flag is lowercase with underscores.
   - ROT13 shift: A -> N, B -> O, etc.
   - Flag format: flag{your_decoded_string_here} or just your_decoded_string_here

2. SQL Injection:
   - Try placing ' OR '1'='1 inside username/password.
   - Comments in SQL like -- or /* or # can bypass the rest of the statement.

3. Hash Cracker:
   - Numeric admin passcode of length 5 (e.g. 12345).
   - Use Python's hashlib or an online MD5 cracker to find the matching hash.

4. Path Traversal:
   - Submit a path that goes up from the current directory using `../` multiple times.
   - Aim to reach `/etc/shadow` or similar files.
