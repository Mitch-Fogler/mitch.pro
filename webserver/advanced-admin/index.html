What Is Logged

transparent policy

User engagement: Total page visit counts per user for site health and trend analysis. Exact timestamps and IP addresses are not logged.

mitch.prox Site Audit: Logs of external sites visited through the proxy for security oversight and abuse prevention.

Admin actions: Detailed logs of who used an admin feature, what changed, and when it happened.

Moderation: Reported chat safety signals, timestamps, and involved users where available.

Chat history: Metadata for encrypted DMs and full history for the Premium Sanctum are available for safety monitoring.
